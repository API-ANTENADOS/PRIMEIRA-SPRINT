Primeira Sprint - Antenados
-
*O projeto Observatório de Inovações realiza o mapeamento e a análise do ecossistema de telecomunicações de São José dos Campos, utilizando dados públicos e ferramentas de Business Intelligence para identificar empresas, empregos, indicadores econômicos e oportunidades estratégicas para o setor.*

Objetivo do Projeto
-
*O projeto Observatório de Inovações tem como objetivo mapear o ecossistema de inovação de São José dos Campos, com foco na logística e nas operações do setor de telecomunicações. A iniciativa envolve identificar empresas, estruturar uma base de dados confiável e desenvolver ferramentas visuais para transformar informações em conhecimento estratégico.*

Dashboard - Empresas de Telecomunicações em SJC
-
*O dashboard apresenta a distribuição geográfica das empresas de telecomunicações e fabricantes de equipamentos em São José dos Campos, destacando a concentração de vínculos empregatícios por CEP entre 2020 e 2025. A análise permite identificar as regiões com maior atividade econômica e compreender a distribuição espacial do setor no município.*
